## Summary

A code editor is where you write code. An IDE combines the editor, terminal, and other tools into one application. Learn the interface so you are never lost.

## VS Code Interface

VS Code organizes key features around side panels and the bottom bar. Get to know these areas so navigation feels natural from the start.

### Key Points

- Explorer: view and manage project files
- Integrated Terminal: run commands without leaving the editor
- Search: find text across the whole project
- Extension Marketplace: install additional features

<!-- visual: ide-nav -->

## Essential Extensions

Extensions add capabilities to VS Code. Install ones that boost productivity and catch errors early.

### Key Points

- Error Lens: show errors inline in the code
- Live Server: auto-open a web page preview
- Prettier: format code consistently
- Live Share: collaborate on code with others

## Running Code

Run scripts directly from the editor. Save your file before running. Watch the output panel for error messages.

### Key Points

- Live Server / Live Preview for HTML/CSS
- Integrated terminal for direct execution
- npm run scripts for existing projects
- Watch the output panel for error messages
