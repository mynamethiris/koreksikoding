## Summary

AI can be a good learning assistant. Use it to explain concepts, provide examples, and clean up code. Remember: AI is a tool, not a replacement for your thinking.

## Using AI to Learn

AI explains concepts, gives code examples, answers questions. Give clear instructions for relevant responses.

### Key Points

- Ask for explanations with concrete examples
- Let AI break complex concepts into small steps
- Use AI to translate foreign terms

## Setting the Right Role

Assign the AI a "role" so its tone and depth match your learning goal. Example: "You are a patient, beginner-friendly programming teacher."

### Key Points

- You are a ... teacher, reviewer, expert
- Match the tone to your goal
- State context and difficulty level

## Refactoring and Code Explanation

Ask AI to explain tricky lines, suggest cleaner structure, or add comments. AI helps understand code written by others.

### Key Points

- Ask for line-by-line explanations
- AI can suggest a cleaner code structure
- Use AI to add comments to existing code

## Limitations and Verification

AI is not perfect, it can give wrong answers (hallucination). Always test code manually. Explain results back to yourself.

### Key Points

- AI can give incorrect answers
- Always run code to verify
- Re-explain results to yourself
