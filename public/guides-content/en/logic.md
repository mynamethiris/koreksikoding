## Summary

Programming logic is the foundation of algorithmic thinking. Master this first, then pick a language.

## Variables and Data Types

A variable is a name that stores a value. Think of a labeled box: the label is the variable name, the content is the value. Basic types: integer, float, string, boolean.

### Key Points

- Use descriptive variable names
- Values can change
- Basic types: integer, float, string, boolean

## Operators

Operators are symbols that perform operations on values. Arithmetic for calculation, comparison for comparing, logical for combining conditions.

### Key Points

- Arithmetic: +, -, *, /
- Comparison: ==, >, <, >=, <=
- Logical: AND, OR, NOT

## Conditionals

Use if, else if, else to make decisions. If condition is true run branch A, otherwise run branch B.

### Key Points

- if: run when condition is true
- else: run when condition is false
- else if: add another condition

## Loops

Repeat actions until a condition is met. For fixed count, while for condition, always ensure a stopping point.

### Key Points

- for: repeat a fixed number of times
- while: repeat until condition is false
- always ensure a stopping point

## Functions

A function is a reusable block of code. Takes parameters, returns a value. Breaks code into modular pieces.

### Key Points

- Parameters: input to the function
- Return value: output from the function
- Code becomes modular and reusable

## Pseudocode

Write ideas in plain language before coding. Focus on logic, not syntax.

### Key Points

- Use clear, natural language
- One action per line
- Test logic before turning into code
