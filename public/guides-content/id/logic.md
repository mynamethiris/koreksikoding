## Ringkasan

Logika pemrograman adalah fondasi berpikir algoritmik. Kuatkan ini dulu, baru pilih bahasa pemrograman.

## Variabel dan Tipe Data

Variabel adalah nama yang menyimpan nilai. Bayangkan kotak berlabel: labelnya nama variabel, isinya nilainya. Tipe data dasar: integer, float, string, boolean.

### Poin Utama

- Nama variabel yang deskriptif
- Nilai bisa diubah
- Tipe dasar: integer, float, string, boolean

## Operator

Operator adalah simbol untuk operasi pada nilai. Aritmatika untuk hitung, komparasi untuk banding, logika untuk gabung kondisi.

### Poin Utama

- Aritmatika: +, -, *, /
- Komparasi: ==, >, <, >=, <=
- Logika: AND, OR, NOT

## Pengkondisian

Gunakan if, else if, else untuk keputusan. Jika kondisi benar jalankan cabang A, jika tidak jalankan cabang B.

### Poin Utama

- if: jalankan saat kondisi benar
- else: jalankan saat kondisi salah
- else if: tambah kondisi lain

## Perulangan

Ulangi aksi sampai kondisi terpenuhi. For untuk jumlah tetap, while untuk kondisi, pastikan ada cara berhenti.

### Poin Utama

- for: ulang jumlah tetap
- while: ulang sampai kondisi salah
- selalu pastikan ada penghentian

## Fungsi

Fungsi adalah blok kode yang bisa dipanggil kembali. Menerima parameter, mengembalikan nilai return. Memecah kode jadi modular.

### Poin Utama

- Parameter: input ke fungsi
- Return value: output dari fungsi
- Kode jadi rapi dan reusable

## Pseudocode

Tulis ide dalam bahasa alami sebelum kode. Fokus logika, bukan sintaks.

### Poin Utama

- Bahasa alami yang jelas
- Satu aksi per baris
- Uji logika sebelum jadi kode
