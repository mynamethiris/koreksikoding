## Ringkasan

Code editor adalah tempat menulis kode. IDE menyatukan editor, terminal, dan alat bantu dalam satu aplikasi. Kenali antarmukanya agar tidak tersesat.

## Antarmuka VS Code

VS Code menyusun fitur utama di panel samping dan bilah bawah. Kenali area ini agar navigasi nyaman sejak pertama kali pakai.

### Poin Utama

- Explorer: lihat dan kelola berkas proyek
- Terminal Terintegrasi: jalankan perintah tanpa keluar editor
- Search: cari teks di seluruh proyek
- Extension Marketplace: pasang fitur tambahan

<!-- visual: ide-nav -->

## Ekstensi Penting

Ekstensi menambah fitur VS Code. Pasang yang meningkatkan produktivitas dan menangkap error sejak dini.

### Poin Utama

- Error Lens: tampilkan error langsung di kode
- Live Server: buka preview web otomatis
- Prettier: format kode rapi otomatis
- Live Share: kolaborasi menulis kode dengan rekan

## Menjalankan Kode

Jalankan script langsung dari editor. Simpan file sebelum menjalankan. Perhatikan pesan error di panel output.

### Poin Utama

- Live Server / Live Preview untuk HTML/CSS
- Terminal terintegrasi untuk eksekusi langsung
- npm run scripts untuk proyek yang sudah ada
- Perhatikan pesan error di panel output
